# Search Cost Transfer Worksheet

**Optional worksheet; continue a separate copy of the completed core project.**
Reading this worksheet imports no program. Use sizes 1, 4, 16 and 64 with sorted
values generated by the same rule. For each size, choose a first match, a last
match and an absent target. Include a duplicate run and empty input separately.

Predict the first index and linear comparison count before running each case.
Record the actual binary count and explain why different target positions can
change it. The counters exclude sortedness checking; describe that extra scan
and why it changes a claim about the full driver. Submit the fixtures, a table
of predicted/actual results, and a plain-language worst-case comparison. Do
not use timing as the only evidence. This extends the core project rather than
requiring another implementation of an unrelated numeric transformation.

The legacy `starter` and `solution` subfolders remain available for older
catalog links and saved imports. Their numeric-transform exercise is not this
worksheet or a new DSA assignment. Use the completed setup search project above.
